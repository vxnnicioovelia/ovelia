# Nota editorial — Liturgia e Bíblia

Este documento substitui instruções antigas desta pasta que descreviam a publicação automática de textos integrais.

- A Liturgia da Ovelia mantém data, celebração e referências quando os dados estão disponíveis.
- A API comunitária configurada é `https://liturgia.up.railway.app/v2/`. A presença de texto nessa API não comprova autorização para redistribuição pública.
- A publicação de textos integrais permanece desativada até haver licença documentada.
- A autorização solicitada à Editora Ave-Maria para a tradução bíblica continua pendente.
- A Bíblia mantém sua estrutura de 73 livros, mas não deve ser descrita como contendo os textos integrais enquanto eles não estiverem licenciados, presentes e validados.
- Para consulta externa da Liturgia, a interface oferece um link identificado para o site da Canção Nova: https://liturgia.cancaonova.com/pb/.

Não execute instruções antigas de importação de textos integrais sem revisar a licença e os workflows.
