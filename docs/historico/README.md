# Histórico de materiais

Os arquivos desta pasta foram retirados da raiz durante a organização de 02/11/2026. Permanecem preservados para consulta; não são carregados pela aplicação web.

- `instrucoes/`: notas antigas de atualização e recuperação.
- `relatorios/`: registros de auditorias, correções e testes anteriores.
- `roteiros/`: roteiros de verificação manual.
- `inventarios/`: listas e checksums de pacotes anteriores.
- `pacotes/`: ZIPs antigos.
- `workflows/`: rascunhos e cópias de automações que não estavam ativos em `.github/workflows/`.
- `modulos-nao-integrados/`: arquivos duplicados, placeholders vazios e módulos não conectados à página atual.

Os nomes e datas dos arquivos originais foram preservados quando possível. O material histórico não deve ser tratado como instrução atual do projeto.
