# Ovelia — Parte 14: correção de leitura bíblica no iPhone

## Arquivos deste pacote
- `index.html` — substituir na raiz do repositório.
- `biblia.js` — substituir na raiz do repositório.
- `biblia.css` — substituir na raiz do repositório.
- `sw.js` — substituir na raiz do repositório.
- `RELATORIO-PARTE-14-BIBLIA.md` — documento de referência; pode ficar fora do site.

## Aplicação pelo iPhone
1. Guarde um backup do ZIP atual do site.
2. No GitHub, abra cada arquivo na raiz, toque no lápis e substitua o conteúdo pelo arquivo correspondente deste pacote. Não envie os arquivos de documentação para a raiz pública se não quiser publicá-los.
3. Faça commit somente depois de conferir os quatro arquivos.
4. Abra o site e recarregue. Se o cache antigo persistir, feche a aba e abra novamente; o nome do cache foi incrementado.

## Limite importante
Este pacote corrige a navegação visual do catálogo e o layout de leitura móvel. Ele NÃO contém os textos integrais da Bíblia. As traduções continuam `em_preparacao` até que a fonte USFM real seja anexada, importada e validada. Portanto, os versículos não aparecerão ainda. Não marque BPM como disponível sem validar os arquivos gerados e confirmar a ativação editorial.
