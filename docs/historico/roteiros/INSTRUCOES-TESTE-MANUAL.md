# Instruções de teste manual — Ovelia Atualização 1.1

## Antes de testar
- Use os arquivos dentro de `PUBLICAR/`.
- Não copie a pasta `BACKUP/` para a raiz do GitHub Pages.
- Nenhuma publicação foi realizada automaticamente.

## No iPhone (Safari) ou Android (Chrome)
1. Abra o site publicado e acesse **Liturgia Diária**.
2. Confira data, celebração, títulos e referências.
3. Selecione ontem, hoje e amanhã no calendário/seletor. A data e as referências devem acompanhar a seleção; não deve haver conteúdo de outro dia.
4. Quando o texto integral não estiver autorizado, o aviso editorial deve permanecer visível. Não espere que os textos integrais apareçam nesta versão.
5. Teste fonte ampliada, tema claro e escuro e rolagem até o final da seção. Não deve haver rolagem horizontal.
6. Se não houver dados para uma data, deve aparecer a mensagem de indisponibilidade e não uma leitura inventada.
7. Após publicar, feche e reabra o site para verificar que a versão atualizada do cache foi carregada.

## O que não foi possível confirmar
- A renderização visual completa em dispositivos físicos.
- A execução real do workflow GitHub Actions.
- A permissão legal de redistribuição da fonte atual.
- A reprodução de textos integrais: permanece bloqueada até licença escrita e metadados corretos.
